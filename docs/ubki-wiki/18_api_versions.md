Детальніше

Передача даних в бюро підтримує версійність. Зміни, що з'являються отримують номер версії. Для ідентифікації певної версії використовується дата. Доступно до тестування - зміни доступні на тестовому/бойовому оточенні. Дата версії - версія актуальна за замовчуванням на бойовому оточенні.
